# PULSE 2.3

Архитектурный сброс PULSE без изменения текущего интерфейса.

## Структура
- `server.js` — API, Telegram, сбор событий.
- `public/index.html` — только разметка.
- `public/css/app.css` — весь визуальный слой.
- `public/js/app.js` — UI и навигация.
- `public/js/news-normalizer.js` — нормализация отображаемых новостей и языковой фильтр.
- `public/js/image-loader.js` — загрузка, prefetch и fallback реальных изображений источников.

Важно: PULSE не подставляет тематические картинки в новостные карточки. Если изображение источника недоступно, показывается нейтральный fallback.

## После загрузки
1. Удалить старые файлы репозитория.
2. Залить содержимое этого архива.
3. Commit/push.
4. В Render выполнить Clear build cache & deploy.
